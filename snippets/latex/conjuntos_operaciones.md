| Significado               | LaTeX                               |
| ------------------------- | ------------------------------------|
| Pertenece a               | `\in`                               |
| No pertenece a            | `\notin`                            |
| Contiene como elemento    | `\ni`                               |
| Subconjunto               | `\subset`                           |
| Subconjunto o igual       | `\subseteq`                         |
| Subconjunto propio        | `\subsetneq`                        |
| No es subconjunto         | `\nsubseteq`                        |
| Superconjunto             | `\supset`                           |
| Superconjunto o igual     | `\supseteq`                         |
| Superconjunto propio      | `\supsetneq`                        |
| Unión                     | `\cup`                              |
| Unión grande              | `\bigcup`                           |
| Intersección              | `\cap`                              |
| Intersección grande       | `\bigcap`                           |
| Diferencia                | `\setminus`                         |
| Diferencia (alternativa)  | `\smallsetminus`                    |
| Complemento               | `A^c`                               |
| Complemento (barra)       | `\overline{A}`                      |
| Conjunto vacío            | `\emptyset`                         |
| Conjunto vacío (variante) | `\varnothing`                       |
| Producto cartesiano       | `\times`                            |
| Potencia de un conjunto   | `\mathcal{P}(A)`                    |
| Existe                    | `\exists`                           |
| Existe único              | `\exists!`                          |
| Para todo                 | `\forall`                           |
| Tal que                   | `\mid`                              |
| Igual por definición      | `:=` o `\coloneqq` (con `mathtools`)|
