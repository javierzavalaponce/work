
# Redes neuronales 

Redes neuronales: modelos computacionales inspirados en el cerebro biológico, compuestos por capas de neuronas artificiales interconectadas que transforman datos mediante pesos y funciones de activación para aprender representaciones y realizar tareas como clasificación, regresión y generación.

## Redes neuronales convolucionales (CNN)

* Para procesar datos con estructura de *grid* (imágenes, videos).
* Usan filtros (convoluciones) para detectar patrones espaciales como bordes, texturas, objetos.
* Ejemplo: Reconocimiento facial, diagnóstico por radiografías, etc

\vspace{1cm}


## Redes neuronales recurrentes (RNN)

* Red que tiene "memoria" mediante bucles internos. 
* Procesa secuencias, datos donde el orden importa (series temporales, texto, audio).
* La salida actual depende de entradas actuales y anteriores

Variantes famosas: LSTM, GRU (solucionan problemas de memoria a largo plazo).
Ejemplo: Traducción automática, generación de texto, etc.
