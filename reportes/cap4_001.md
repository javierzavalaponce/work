## Capitulo 1 . Introducción y revisión de principios básicos.

* Un sistema puede verse como una *caja negra* ,
a veces no es importante lo que tiene dentro, sino la relación entre la salida y la entrada. El término sistema se emplea para describir un conjunto de comportamientos que intearctúan al rededor de los cuales se dibuja una frontera imaginaria.

* Un sistema de control es aquél en el que la salida del sistema se controla
para tener un valor específico o cambiarlo. [@wbolton]

**Sistema en Lazo Cerrado**

* Un sistema de control en lazo cerrado proporciona un medio a través del cual
una señal relacionada con la salida obtenida se realimenta para comparacion con la referencia. 
    1. *Retro negativa:* error = referencia - realimentación
    2. *Retro positiva:* error = referencia + realimentación

```{=latex}
\begin{equation}
\begin{aligned}
  salida/entrada = G/(1+GH)
\end{aligned}
\end{equation}
```

G: cuánto se amplifica el error.

H: factor de realimentación que pondera la señal de salida medida.
