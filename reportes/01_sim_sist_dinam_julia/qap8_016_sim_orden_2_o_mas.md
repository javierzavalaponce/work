# Simulación de sistemas de orden 2

## La Ecuación del Péndulo Amortiguado

El movimiento de un péndulo simple con fricción se describe por:

```{=latex}
\[
\ddot{\theta} + \frac{b}{m}\,\dot{\theta} + \frac{g}{L}\,\sin(\theta) = 0
\]
```

Donde:

* $\theta$ = ángulo del péndulo

* $b$ = coeficiente de fricción viscosa $(N·m·s/rad)$

* $m$ = masa del péndulo $(k)$

* $L$ = longitud del péndulo $(m)$

* $g$ = gravedad $(9.81 m/s^2)$
